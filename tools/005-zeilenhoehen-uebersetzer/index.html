Zeilenhöhen-Übersetzer

Welches Problem es löst

  • Figma-Variablen kennen für die Zeilenhöhe nur feste Pixel. Relative Werte wie 150 % oder 1,5, so wie CSS sie braucht, lassen sich nicht als Variable anlegen. Der Wunsch läuft seit Jahren. Figma-Forum 21970, Bestätigung in der Doku von Tokens Studio
  • Dieselbe Zeilenhöhe erscheint in Figma mit zwei verschiedenen Prozentwerten (133 % in der Ansicht, 109 % in der Tabelle), und Entwickler wissen nicht, welcher gilt. Figma-Forum 32392
  • „Auto“ in Figma entspricht nicht line-height: normal im Browser; im Code wird die Textbox anders hoch als im Entwurf. Figma-Forum 57490, Figma-Forum 66344
Gelesen am 28.11.2026, Quellen in meta/probleme.md.

So sieht das Problem aus

Die Zeilenhöhe ist der Abstand von einer Textzeile zur nächsten. In Figma steht sie oft in Pixeln, im Code sollte sie eine Verhältniszahl sein (1,5 heißt: anderthalbmal so hoch wie die Schrift). Steht im Code ein fester Pixelwert, rutschen die Zeilen übereinander, sobald jemand die Schrift im Browser größer stellt.

Trage deine Textstile ein, eine Zeile pro Stil: Name, Schriftgröße, Zeilenhöhe. Die Zeilenhöhe so, wie sie in Figma steht: 24 oder 24px, 150%, 1.5 oder auto. Das Tool rechnet alles in Pixel, Verhältniszahl und Figma-Prozent um, rastet auf dein Raster ein und gibt CSS, Figma-Variablen und Token-JSON aus. Alles bleibt in deinem Browser.

Tool 005 / 28.11.2026. Rechenweg: Pixel = Schrift × Faktor; Faktor = Pixel ÷ Schrift (auf vier Stellen gerundet); Figma-Prozent = Faktor × 100. Eine Zahl ohne Einheit bis 4 gilt als Faktor, darüber als Pixel. „auto“ hängt in Figma und im Browser von der Schrift ab; der Wert oben ist nur eine Annahme, bitte festlegen. Im Raster wird auf das nächste Vielfache gerundet, bei Gleichstand nach oben.
