Icon-Export-Reiniger

Welches Problem es löst

  • Figma schreibt beim SVG-Export feste Hex-Werte, auch wenn das Icon mit Variablen gefärbt ist. Gewünscht wird der Variablenname mit Hex als Ersatzwert. Figma-Forum, dasselbe bei Habr
  • Teams putzen jeden Export von Hand oder per Skript nach: clip-rule/evenodd entfernen, Schwarz durch currentColor ersetzen. levimcg.com, allsvgicons.com
  • Werkzeuge wie SVGOMG verkleinern einzelne Dateien, ordnen Farben aber keinen Tokens zu und prüfen nicht, ob ein ganzes Set einheitlich ist (gleiche viewBox, gleiche Strichstärke).
Belegt am 15.11.2026, Quellen in meta/probleme.md.

So sieht das Problem aus

Exportiert man ein Icon aus Figma, steht die Farbe fest im Code, zum Beispiel Fast-Schwarz. Auf einer dunklen Seite verschwindet das Icon, und für jede Farbe bräuchte man eine eigene Datei. Richtig wäre: Das Icon übernimmt die Farbe der Umgebung oder die des Tokens.

Zieh mehrere SVG-Dateien hierher oder füge Markup ein. Das Tool sammelt alle Farben des Sets, du ordnest jede einer Regel zu: currentColor, eine CSS-Variable mit Ersatzwert, oder unverändert. Dann bereinigt es jede Datei und prüft das Set auf Ausreißer. Alles bleibt in deinem Browser.
