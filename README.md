# Werkbank Designsysteme

Jeden Tag ein kleines, lauffähiges Webtool für ein echtes Problem aus der Welt der
Designsysteme. Die Probleme stammen aus Recherche in Foren, Reddit, Hacker News und
GitHub-Issues, jedes mit Quelle.

- Sammelseite: [`index.html`](index.html)
- Tools: `tools/<nnn>-<name>/index.html`, jedes eine einzelne Datei, läuft offline
- Problem-Vorrat mit Quellen: [`meta/probleme.md`](meta/probleme.md)
- Betriebsanleitung für die täglichen Läufe: [`CLAUDE.md`](CLAUDE.md)

Der frühere Inhalt (Tagebuch „Notation“, bis 13.11.2026) liegt im Tag
`archiv-tagebuch-notation`.
